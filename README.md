# Hub Nexus's Homebrew tap

Write, the free Markdown editor for the desktop that publishes to Hub Nexus:

    brew install --cask hubnx/tap/write

Each release of Write updates `Casks/write.rb` (version and checksum) from the
release's files; the app updates itself after that, so Homebrew only installs.
About Write: https://www.hubnx.com/apps
